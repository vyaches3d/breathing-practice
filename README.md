# Дыхательные практики

Самодостаточные HTML-файлы: дыхательные упражнения и таймер обратного отсчёта.
Открываются двойным кликом, работают офлайн, без сборки и зависимостей.

## Возможности

- Четыре фазы, настраиваемые в секундах: вдох → задержка → выдох → задержка.
  Фаза с нулевой длительностью пропускается.
- Пресеты: бокс 4-4-4-4, 4-7-8, когерентное дыхание 2-2 (по умолчанию).
- Живое изменение темпа прямо во время практики (×0.50 … ×2.50, шаг 5%):
  все фазы растягиваются пропорционально, круг и звук не сбиваются.
- Лимит сессии по минутам или циклам с автостопом.
- Визуал: дышащий круг, название фазы, обратный отсчёт, счётчик циклов и времени.
- Настройки сохраняются в localStorage.

## Звук

Всё синтезируется в браузере через Web Audio API, звуковых файлов нет.

- **Тянущиеся**: пэды (тёплый, мягкий, стеклянный, глубокий, дрон), поющая чаша, хор, флейта.
- **Щипковые**: маримба, ханг, музыкальная шкатулка — арпеджио по пентатонике,
  вверх на вдохе и вниз на выдохе.
- **Колокольчики** и **тишина**.

Кнопка «Проба» проигрывает вдох-выдох выбранным тембром, не запуская сессию.

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| Пробел | пауза / продолжить |
| Esc | стоп |
| ↑ / ↓ | быстрее / медленнее |

## Использование

Открыть [`breathing.html`](breathing.html) в любом современном браузере.
Звук включается по первому нажатию «Старт» — этого требуют правила автозапуска аудио.

## Таймер обратного отсчёта

Открыть [`timer.html`](timer.html).

- Ввод времени в формате ЧЧ:ММ:СС, пресеты 5 / 15 / 25 / 45 минут.
- Круговой индикатор прогресса, обратный отсчёт в заголовке вкладки.
- По завершении — вспышка экрана и звуковой сигнал (Web Audio API).
- Последнее выбранное время сохраняется в localStorage.
- Два кружочка-пикера: цвет интерфейса (оранжевый по умолчанию) и цвет фона (тёплый графит
  по умолчанию) — любой цвет через системную палитру, текст автоматически подстраивается
  под контраст, выбор сохраняется в localStorage.
- Жирность шрифта: тонкий / обычный / жирный (по умолчанию) / чёрный — сохраняется в localStorage.
- Шрифт цифр: гротеск (Space Grotesk, по умолчанию, встроен в файл) / обычный (системный) /
  моноширинный / с засечками — сохраняется в localStorage.
- Кнопка полноэкранного режима (иконка в правом верхнем углу). В полноэкранном режиме
  на экране остаются только кольцо с цифрами и кнопка возврата — все настройки скрыты.
- Экран не гаснет во время отсчёта (Wake Lock API) — работает на HTTPS/GitHub Pages,
  в браузерах с поддержкой API (Chrome/Edge на Android и десктопе).
- Горячие клавиши: `Пробел` — старт/пауза, `Esc` — сброс, `F` — полный экран, `↑`/`↓` — ±1 минута.
