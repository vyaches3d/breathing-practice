# Дыхательные практики

Один самодостаточный HTML-файл для дыхательных упражнений. Открывается двойным кликом,
работает офлайн, без сборки и зависимостей.

## Возможности

- Четыре фазы, настраиваемые в секундах: вдох → задержка → выдох → задержка.
  Фаза с нулевой длительностью пропускается.
- Пресеты: бокс 4-4-4-4, 4-7-8, когерентное дыхание 5-5.
- Живое изменение темпа прямо во время практики (×0.50 … ×2.50, шаг 5%):
  все фазы растягиваются пропорционально, круг и звук не сбиваются.
- Лимит сессии по минутам или циклам с автостопом.
- Визуал: дышащий круг, название фазы, обратный отсчёт, счётчик циклов и времени.
- Настройки сохраняются в localStorage.

## Звук

Всё синтезируется в браузере через Web Audio API, звуковых файлов нет.

- **Тянущиеся**: пэды (тёплый, мягкий, стеклянный, глубокий, дрон), поющая чаша, хор, флейта.
- **Щипковые**: маримба, ханг, музыкальная шкатулка — арпеджио по пентатонике,
  вверх на вдохе и вниз на выдохе.
- **Колокольчики** и **тишина**.

Кнопка «Проба» проигрывает вдох-выдох выбранным тембром, не запуская сессию.

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| Пробел | пауза / продолжить |
| Esc | стоп |
| ↑ / ↓ | быстрее / медленнее |

## Использование

Открыть [`breathing.html`](breathing.html) в любом современном браузере.
Звук включается по первому нажатию «Старт» — этого требуют правила автозапуска аудио.
